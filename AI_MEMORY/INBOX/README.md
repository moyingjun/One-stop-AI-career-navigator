# AI_MEMORY INBOX

`AI_MEMORY/INBOX/` 是给 Hermes Project Steward 的交付报告收件箱。

说明：

- Codex / Trae / Kiro / Cursor / WorkBuddy / OpenCode / Antigravity 等工具完成重要任务后，应在这里留下结构化报告。
- 普通问答不写 INBOX。
- 只读分析任务可选择不写 INBOX，除非用户明确要求记录。
- 修改代码、修改规则、完成审计、发现风险、产生新决策时，建议写入 INBOX。
- Hermes 定期读取 INBOX 后，判断是否更新 `CURRENT_STATE.md`、`TASK_LOG.md`、`PROJECT_BRIEF.md`。
- INBOX 中内容是“待消化记录”，不等同于已确认事实。
- 未经 Hermes / OpenCode 整理前，不得把 INBOX 内容当成最高事实源。
- 写入时优先参考 `AI_MEMORY/INBOX/TEMPLATE.md`。

建议文件命名：

- `YYYY-MM-DD-tool-role-task.md`

示例：

- `2026-06-05-codex-implementer-premium-interview-fix.md`
- `2026-06-05-opencode-memory-maintainer-hermes-policy-update.md`
- `2026-06-05-trae-ui-polisher-dashboard-card.md`
